# Malus Privacy Policy

Last updated: 26 September 2026

Malus is a Chrome extension that converts the webpage a user is currently viewing into a Markdown file. Malus is designed to work locally and does not operate a remote service.

## Information Malus handles

When the user explicitly opens Malus and selects **Save as Markdown**, the extension temporarily accesses the active webpage. It may process:

- The page title, URL, language, author, publication date, and site name when available.
- The rendered text and semantic page structure, including headings, paragraphs, lists, links, images, quotations, code, and tables.
- Job-specific information such as title, company, location, and job description when the active page is recognized as a job listing.

This information can include website content and the URL of the active page. Malus does not access other tabs as part of this operation.

## How information is used

Malus uses the active page information only to create the Markdown file requested by the user. Processing occurs locally in the browser.

Malus does not:

- Send webpage content, URLs, browsing activity, or generated files to the developer or any third party.
- Store captured webpage content remotely.
- Retain a history of pages the user has converted.
- Sell personal information or webpage data.
- Use information for advertising, profiling, analytics, creditworthiness, or purposes unrelated to webpage conversion.
- Use cookies, tracking pixels, telemetry, or external analytics services.

The generated Markdown file is downloaded through the browser to a location controlled by the user. The user's browser and operating system may independently retain normal download history or file metadata under their own policies.

## Permissions

Malus requests only these Chrome permissions:

- `activeTab`: provides temporary access to the current tab after the user invokes the extension.
- `scripting`: runs the local extraction code in that active tab so Malus can read the rendered content selected for conversion.

Malus does not request persistent access to all websites.

## Data sharing and retention

Malus does not transmit captured information, so the developer does not receive, share, or retain it. The user controls the generated Markdown file after download.

## Children

Malus is a general productivity tool and is not directed to children. It does not knowingly collect personal information from children or other users.

## Changes to this policy

If Malus's data practices change, this policy and the Chrome Web Store disclosures will be updated before those changes are released. A new effective date will be shown above.
