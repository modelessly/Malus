# Chrome Web Store Listing

## Product name

Malus — Webpage to Markdown

## Summary

Save readable webpages and supported job listings as clean, local Markdown files.

## Category

Workflow & Planning

## Language

English

## Detailed description

Malus turns the useful content of the webpage you are viewing into a clean Markdown file with one explicit click.

Open a fully loaded article, documentation page, reference page, or supported job listing. Select the Malus toolbar icon, choose **Save as Markdown**, and receive a portable `.md` file in your browser's download location.

Malus preserves useful page structure when available:

- Titles and headings
- Paragraphs and emphasis
- Lists and quotations
- Links and images
- Code blocks and tables
- Canonical source, author, publication date, language, and capture date
- Job title, company, location, and related job metadata on supported job pages

Malus removes recognizable navigation, forms, cookie prompts, advertising, recommendations, and similar page chrome. Specialized job extraction is attempted first; other readable webpages use a general semantic-content extractor.

### Local by design

Page conversion happens locally in Chrome. Malus has no account system, backend, analytics, telemetry, AI service, advertising, or external content processor. Page content and generated files are not uploaded to the developer or shared with third parties.

### Permissions

Malus uses `activeTab` and `scripting` only after the user invokes the extension. It does not request persistent access to every website.

### Limitations

Malus works with ordinary rendered HTML that Chrome allows an extension to inspect. It cannot reliably convert browser-internal pages, protected or inaccessible frames, canvas-only applications, embedded PDFs, media meaning, inaccessible paywalled content, or content that has not loaded.
