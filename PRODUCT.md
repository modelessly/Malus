# PRODUCT.md

## Product Name

Malus

## One-Sentence Description

A local-first Chrome extension that turns the useful content of the current webpage into a clean Markdown file with one click.

## Vision

Malus gives people a durable, portable copy of useful web content before it changes or disappears. Capture should feel immediate and trustworthy, producing plain files that remain useful in any notes system or editor.

## Core User

People who research, read, document, or track material in Markdown-friendly tools and want a clean record without manual copy-and-paste.

## Core Moment

The user is viewing a useful article, reference page, or job listing and decides it is worth saving.

## Product Thesis

If turning a webpage into structured Markdown takes one clear action, people can build portable reference material without another account, cloud service, or workflow.

## What This Product Is

- A focused Chrome toolbar utility.
- A local converter for ordinary rendered HTML pages.
- A layered extractor with richer handling for supported job pages.

## What This Product Is Not

- A promise to reproduce every visual or interactive webpage exactly.
- A browser-internal-page, canvas-app, media, paywall, or protected-document bypass.
- A cloud service, account system, scraper, AI writer, or content library.

## User Promise

On an ordinary fully loaded webpage, the user can download readable Markdown containing the primary available content and source metadata without obvious interface clutter. Supported job pages additionally retain normalized job metadata.

## Success Criteria

- Primary readable content exports with useful structure.
- Missing optional metadata does not prevent export.
- Obvious navigation, controls, ads, and recommendations are excluded.
- Existing specialized job output remains intact.
- Captured content never leaves the browser.
